React Native Reusables Free · MIT

shadcn-style components · NativeWind (Tailwind) · expo-router · universal (iOS/Android/web)

The "shadcn/ui of React Native". Copy-paste components you own, Tailwind classes, first-class dark theme. Big community — most-aligned with the design board I showed you.

  • 40+ primitives — buttons, cards, dialogs, form fields, segmented controls, sheets, toasts
  • Dark theme built in — semantic tokens (background/card/primary/destructive) map 1:1 to our navy+emerald
  • No lock-in — code lives in your repo; restyle per screen freely
